
# Nathanial Story - Personal Portfolio

Welcome to my personal portfolio webpage! This project serves as a digital resume and showcase of my software development journey, featuring my skills, university background, and personal GitHub projects.

## Overview of Technologies

This portfolio is built entirely from scratch without the use of heavy front-end frameworks, ensuring fast load times and a deep understanding of core web technologies.

* **HTML5:** Used for the semantic structure and accessibility of the page.
* **CSS3:** Handles all styling, responsive design formatting, modal layouts, and custom features like the interactive Dark Mode toggle and tooltips.
* **Vanilla JavaScript (ES6+):** Powers the interactive elements of the site. This includes dynamic DOM manipulation, form submission handling (with visual feedback), timed notifications, and `sessionStorage` management to dynamically render the project gallery.

## Dependencies and Running the Page

Because this project is built using native web technologies, there are **no external dependencies, packages, or build tools** required to run it.

### How to Run:

1. Clone or download this repository to your local machine.
2. Navigate to the folder containing the project files.
3. Double-click the `index.html` file to open it directly in any modern web browser (Chrome, Firefox, Safari, Edge).

### Features to Explore:

* **Dark Mode Toggle:** Located in the top right corner. Preferences are saved via `localStorage` so your choice persists across page reloads.
* **Dynamic Project Loading:** The "My Projects" section loads its content dynamically from JavaScript objects stored in `sessionStorage`.
* **Interactive Contact Form:** Features built-in HTML5 validation and a simulated JavaScript submission process with timed visual feedback.
